## What we're pitching (one-liner for every hook below)
Gradata is procedural memory for AI coding agents. Agents learn from
corrections, *graduate* durable rules, and recall the right procedure
lazily at the right moment — instead of bloating every prompt with a
giant CLAUDE.md. The wedge is cross-agent identity: one memory that
follows the developer across Claude Code, Codex, Cursor, Gemini, Hermes
and OpenCode. Lazy recall > eager injection. MCP > system prompt.
